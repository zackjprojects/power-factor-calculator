# power-factor-calculator
A Python tool that calculates the required capacitor size to correct the power factor of multiple parallel electrical loads. Users input voltage, frequency, and load details, and the script outputs total power values and the capacitor needed for unity power factor.
# Power Factor Correction Calculator

This Python script calculates the capacitor value needed to correct the power factor of parallel electrical loads.

## How to Run
1. Make sure Python 3 is installed.
2. Run with: `python main.py`
3. Follow the prompts.

## Example Input
- Voltage: 240
- Frequency: 50
- Number of Loads: 3
